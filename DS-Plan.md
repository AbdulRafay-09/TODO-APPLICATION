# Data Structure Planning Table

| Operation              | Data Structure Used                        | Reason for Choosing DS                                                                     | Assigned Member     |
|------------------------|--------------------------------------------|--------------------------------------------------------------------------------------------|---------------------|
| **Add New Task** | Singly Linked List (Dynamic Node Creation) | Best because we can add unlimited tasks without fixing a size beforehand (unlike Arrays).  | **Abdul Rafay** |
| **Delete Task** | Singly Linked List (Pointer Manipulation)  | Efficient because we just change pointers to remove a task; no need to shift all elements. | **Huzaifa Imran** |
| **View All Tasks** | Singly Linked List (Traversal)             | Natural sequential flow (Start to End) matches how we read a To-Do list.                   | **Hamza Aslam** |
| **Mark Task Complete** | Singly Linked List (Node Update)           | Easy to access a specific node during traversal and update its status.                     | **Azan Zaman** |
| **Search for Task** | Linear Search (Traversal)                  | Simple to iterate through the chain to find if a task exists.                              | **Team** |
