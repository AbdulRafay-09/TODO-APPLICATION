# To-Do List Application (Final Version)
**Group:** The Guardians of the Linked Chain  
**Data Structure:** Singly Linked List (C++)

## Project Summary
This project is a dynamic To-Do List application designed to manage tasks efficiently using Linked Lists. Unlike Arrays, it allows unlimited task insertion and efficient memory usage.

## Key Features
1.  **Add Task:** Inserts a new node at the end of the list.
2.  **View Tasks:** Traverses the list and displays all items.
3.  **Search Task:** Finds if a specific task exists.
4.  **Delete Task:** Removes a node and frees memory.

## How to Run
1.  Compile `src/main.cpp` using any C++ compiler (DevC++, VS Code, OnlineGDB).
2.  Run the executable to see operations in the console.
